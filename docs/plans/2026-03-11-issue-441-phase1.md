# Issue #441 Phase 1 Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Implement the phase-1 scalar and analytic tensor substrate on CPU while keeping the prim protocol, eager AD surface, and capability model strictly CPU/GPU-generic.

**Architecture:** Treat this PR as a substrate-and-surface PR, not a CUDA parity PR. Land real CPU execution for the phase-1 `TensorScalarPrims` and `TensorAnalyticPrims` vocabularies, expand backend-independent scalar AD rules, add generic dyadtensor unary/binary/reduction surfaces, and keep GPU behavior limited to truthful capability reporting plus existing cuTENSOR-backed fast paths.

**Tech Stack:** Rust workspace crates, `tenferro-prims`, `extern/chainrules-scalarops`, `extension/tenferro-dyadtensor`, `strided-rs`, existing cuTENSOR backend, workspace verification commands.
