# CI latency follow-up (#1812)

## Decision

The trusted RunPod workflow now starts from the `in_progress` event of the
workspace-test workflow instead of waiting for that workflow to finish. Both
authorization and final-gate publication require that event status, preserving
#1806's rule that a completed unsuccessful upstream run cannot publish a gate. Its
hosted CUDA/PJRT archive build overlaps the independent CPU, macOS, coverage,
and documentation checks. Paid provisioning remains behind trusted
authorization, change classification, and successful `rustfmt` and `clippy`.
The other checks remain required merge blockers.

The workspace matrix's rust-cache configuration now maps the cache to the
external `CARGO_TARGET_DIR` used by the faer and BLAS lanes. On an exact cache
hit, CI verifies that restored `faer` and all six strided-rs dependency crates
exist under the actual `target/ci/deps` directory; this avoids treating a
cache-hit label for the unused checkout-local target as evidence of reuse.

The CUDA tutorial uses the existing `ci` profile and is archived from
`target/ci`. Tutorial feature activation was narrowed so CUDA no longer
implicitly enables WebGPU; Apple and documentation feature sets explicitly
retain WebGPU where they need it. The shared archive key was rotated because
its build contract changed. Coverage keeps restored instrumented artifacts with
`cargo llvm-cov --no-clean`; thresholds and the existing coverage report remain
authoritative.

## Deferred

Edition 2024 doctest combination and RunPod concurrency-group changes remain
deferred. They need separate timing evidence and, for concurrency, an explicit
review of cancellation and cost behavior. No validation lane or numerical
assertion was removed.

## Verification

Local workflow contract tests, run-profile tests, diff whitespace checks, and
actionlint passed. Hosted evidence still required before claiming the cache
optimization: a cold run must populate the corrected target path, followed by
a warm unchanged-dependency run whose CI log shows the exact cache hit and the
artifact-verification step passing for faer and strided-rs.
